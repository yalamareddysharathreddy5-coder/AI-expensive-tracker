# AI Expense Tracker

An AI-powered expense tracking dashboard built with React and Vite. Log your daily spending, watch category budgets, explore reports, and receive smart AI-style insights into your money habits — all in one place.

## Project Overview

AI Expense Tracker is a fast, client-side web app that helps you manage personal finances. Every transaction, budget and setting is stored locally in your browser using `localStorage`, so there is no backend, no sign-up, and no setup required. A rule-based "AI" engine analyses your transaction history to surface useful insights such as top spending categories, month-over-month changes, budget warnings and savings rate.

## Current Step 1 Features

- **Dashboard** — overview of balance, income, expenses, remaining budget, a 6-month expense bar chart, category summary, recent transactions and AI insight preview
- **Add Expense** — record a transaction with amount, category, description, date and payment method; inline validation and success feedback
- **Expense History** — searchable, filterable table of all transactions with one-click delete
- **Budget** — set a monthly budget and per-category limits with live progress bars and over-budget warnings
- **AI Insights** — rule-generated insights covering top category, month-over-month trends, budget warnings, weekend spending, largest expense, average daily spend and savings rate
- **Reports** — income vs expenses grouped chart, category donut chart, and spending-by-category breakdown
- **Settings** — profile info, monthly income, dark/light mode, currency symbol, notification preferences and sample-data reset

## Technology Stack

- **React 19** — UI library
- **Vite 7** — build tool and dev server
- **React Router DOM v7** — client-side routing
- **React Icons** — icon set (Feather icons)
- **CSS** — custom design system with light/dark themes and responsive layout

## Local Development

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

The app runs at `http://localhost:5173` with hot module reloading.

## Build Instructions

```bash
# Create an optimized production build in dist/
npm run build

# Preview the production build locally
npm run preview
```

## Vercel Deployment

The project is a standard Vite + React application and deploys to Vercel with zero extra configuration.

1. Push the repository to GitHub.
2. In Vercel, click **Add New → Project** and import the GitHub repository.
3. Vercel auto-detects **Vite**, using the default build command `npm run build` and output directory `dist`.
4. No environment variables are required.

The production build is generated with `vite build` and Vercel serves the static `dist/` output.
